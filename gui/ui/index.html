The iDRAC HTML5 console appears here when you connect.

Disconnect (or closing the app) logs the session out of the iDRAC.

The iDRAC Java console is a window of its own (the iDRAC must use the Java plugin: bobcat-cli --enable java). On macOS bobcat docks it here, over this area; that needs the Accessibility permission.

Close its window, or Disconnect, to end the session.

idle

  
  


The Java console needs a Java 8 runtime, and this computer has none that bobcat can use.

bobcat can download Azul Zulu 8 (the Intel build, about 100 MB; it runs under Rosetta on Apple Silicon) into ~/.config/bobcat/java. Its SHA-256 checksum is checked against the one Azul publishes before it is unpacked. Nothing is installed system-wide.
